# 🎬 Billora Motion System

> Version: 1.0

---

# Motion Philosophy

Motion is a core part of the Billora experience.

Animations should never exist for decoration only.

Every animation must improve:

- User understanding
- Visual hierarchy
- Navigation
- Feedback
- Delight

Motion should feel:

- Natural
- Smooth
- Premium
- Purposeful
- Fast

Avoid flashy or distracting animations.

---

# Motion Inspiration

Every animation should feel inspired by products such as:

- Stripe
- Linear
- Framer
- Apple
- Vercel
- Arc Browser
- Raycast

Never imitate exactly.

Take inspiration from their quality and smoothness.

---

# Performance First

Animations must maintain excellent performance.

Rules:

- Prefer GPU accelerated transforms.
- Animate opacity and transform whenever possible.
- Avoid animating width and height.
- Avoid layout thrashing.
- Avoid unnecessary JavaScript animations.

Target:

60 FPS

---

# Animation Principles

Animations should:

Guide attention.

Reduce cognitive load.

Improve understanding.

Never slow users down.

Every motion should have a purpose.

---

# Page Load

Pages should appear smoothly.

Preferred sequence:

Background

↓

Navigation

↓

Hero

↓

Content

↓

Footer

Never animate everything simultaneously.

---

# Page Transitions

Transitions should feel smooth.

Use:

- Fade
- Blur
- Slide
- Scale

Avoid dramatic transitions.

---

# Scroll Animations

Sections should animate only when entering the viewport.

Preferred effects:

Fade

Blur

Slide Up

Scale (small)

Stagger

Never over-animate long pages.

---

# Hero Animation

Hero should immediately create a premium impression.

Recommended effects:

Animated gradient

Aurora background

Floating lights

Floating dashboard

Mouse parallax

Glow effects

Word reveal

Blur reveal

Smooth CTA appearance

Dashboard widgets should animate continuously but subtly.

---

# Navbar

Navbar should:

Start transparent.

Become glass on scroll.

Add blur.

Soft shadow.

Border.

Smooth transition.

Navigation links:

Animated underline.

Buttons:

Glow.

Scale.

Lift.

---

# Buttons

Hover:

Scale

Shadow

Small press animation.

Visible outline.

# Cards

Hover:

Lift

Border glow

# Pricing Cards

Border

# Dashboard Widgets

Slide

# Charts

Charts should animate only on first appearance.

Prefer smooth interpolation.

Avoid distracting movement.

Checkmark animation.

Spinner or progress animation.

# Tables

Soft background transition.

Selection animation.

Avoid unnecessary movement.

# Modals

Fade

Scale

Blur

Closing:

---

# Dropdowns

Scale.

Fast closing.

# Tooltips

Short duration.

# Notifications

# Loading States

# Empty States

CTA.

# Success States

Checkmark

Scale

---

# Error States

Small shake.

Clear explanation.

Recovery action.

Not Allowed:

Continuous bouncing

Buttons

---

# Animation Timing

Very Fast

150ms

Fast

200ms

Standard

300ms

Complex

400–500ms

Never exceed 700ms for UI interactions.

---

# Easing

Prefer:

ease-out

ease-in-out

Spring animations where appropriate.

Avoid linear animations for UI.

---

# Accessibility

Respect reduced-motion preferences.

Animations should never block interaction.

Users should always remain in control.

---

# Final Rule

Motion should make Billora feel alive without becoming distracting.

Every animation should communicate quality, confidence, and professionalism.

If an animation does not improve the user experience, do not add it.
