# 🚀 Billora - AI Project Instructions

## Project Goal

Billora ek premium AI-powered invoicing aur billing SaaS hai.

Ye koi normal dashboard ya template project nahi hai.

Target hai ek world-class SaaS experience create karna jo quality me:

- Stripe
- Linear
- Vercel
- Framer
- Arc Browser
- Notion

ke level ka feel de.

# DESIGN REFERENCES

The folder named "design-reference" is the primary source of inspiration for the entire project.

Before implementing any UI:

- Analyze every image/page inside this folder.
- Reuse its layout principles.
- Match typography.
- Match spacing.
- Match animations.
- Match color palette.
- Match interaction patterns.

Do not create a new design language.

The final UI must look like an evolution of the designs inside the design-reference folder.

Whenever you redesign a section, mention exactly which reference file inspired it.
